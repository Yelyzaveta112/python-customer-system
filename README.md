# python-customer-system
Customer management system using Python OOP with interaction tracking and data handling
The system allows managing customers, tracking interactions, and analyzing customer activity over time.

---

### Features

- Add new customers
- Remove customers
- Update customer contact information
- Store customer interactions
- Track last interaction date
- Identify inactive customers (more than 30 days without interaction)
- Error handling for invalid operations (duplicate email, missing customer, etc.)

---

### Technologies Used

- Python
- datetime module
- Object-Oriented Programming (OOP)

---
### Project Structure

- Customer class — represents a single customer
- CustomerDataSystem class — manages all customers and operations

---

### Demo

The program includes a demo section that:

- Creates a system instance
- Adds customers
- Adds interactions
- Prints customer data
- Demonstrates error handling (ValueError, KeyError)
